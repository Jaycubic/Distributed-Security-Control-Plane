# v0.3.0 — Identity, Correlation & Security Context

This release marks the completion of the initial three implementation phases of the Distributed Security Control Plane.

> **Security should observe and control applications without becoming a dependency of their normal request path.**

## What's Included

### Phase 1 — Architecture Core
- Canonical security event model
- Asynchronous telemetry ingestion
- Decoupled event-stream abstraction
- Selective durable persistence
- Non-blocking application telemetry emitters
- Live operations dashboard
- WebSocket event streaming

### Phase 2 — Detection & Incident Management
- Redis-backed hot operational state
- In-memory sliding-window state
- Deterministic security detection rules
- Credential brute-force detection
- Rapid API enumeration detection
- Unauthorized request-burst detection
- Runtime/container shell detection
- Signal accumulation
- Dynamic risk scoring
- Automated incident synthesis
- Incident lifecycle management
- Incident REST APIs
- Real-time incident streaming
- Operations containment console
- Attack simulation tooling

### Phase 3 — Identity & Cross-Application Correlation
- Canonical entity resolution
- Correlation across IP, session, user, container, and process identifiers
- In-memory security context graph
- TTL-based context eviction
- Cross-application attack-sequence detection
- Capability context inference
- Entity and topology APIs
- Identity and correlation dashboard
- Multi-application attack-chain simulation

## Architecture
```text
APPLICATIONS
     │
     │ asynchronous telemetry
     ▼
SECURITY CONTROL PLANE
     │
     ├── Identity Resolution
     ├── Detection
     ├── Cross-Application Correlation
     ├── Risk & Policy
     ├── Incident Management
     └── Containment Coordination
             │
             │ signed control command
             ▼
        LOCAL AGENT
             │
             ▼
         ENFORCEMENT
```

## Project Status
This is an active early-stage open-source engineering project. APIs, interfaces, deployment assumptions, and implementation details may continue to evolve.
